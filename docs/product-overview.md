# プロダクト概要

## 目的

normalize-numexp は、自然言語文中の数量表現と時間表現を抽出し、機械処理しやすい表現へ規格化する Java ライブラリです。C++ 版 normalizeNumexp を Java へ移植した実装で、文脈解析ではなくルールと辞書の照合を中心に処理します。

## 対象ユーザーと利用シナリオ

Maven/JAR から日本語テキストの数量・時間表現を処理するJavaアプリケーション開発者が主な利用者として想定されます。ただし、利用者像は既存文書で明示されていないため要確認です。

主な利用方法は次の2つです。

- `NormalizeNumexpImpl` を組み込み、規格化結果を文字列または `Expression` として受け取る。
- `Main` に言語とテキストを渡し、規格化文字列を標準出力へ出す。

## 現在の主要機能

- 数量表現 (`numerical`): 数値、単位、上下限、修飾情報を抽出する。
- 絶対時間表現 (`abstime`): 日付・時刻などをISO 8601に準じた形式へ規格化する。
- 相対時間表現 (`reltime`): 絶対時間部分と相対期間部分へ規格化する。
- 持続時間表現 (`duration`): `P` から始まる期間表現へ規格化する。
- 不適切表現、URL等の誤抽出候補を後処理で除外する。
- `ja` と `zh` の文字辞書を選択し、`resources/dic/` のルールを読み込む。日本語辞書が最も充実しており、中国語辞書は一部のみです。

出力フィールドと具体例は `detail.md`、呼び出し契約は `docs/api-spec.md` を参照してください。

## 既知の制約

- 基本的に前後の文脈を考慮しないため、固有名詞、日付と小数、期間と別用途の単位などに曖昧性があります。
- 数値を `double` で保持する箇所があり、丸めが発生し得ます。
- 数字を含まない表現の対応は限定的です。
- 辞書にない助数詞・表記は認識できず、表現によっては辞書とJava実装の両方の変更が必要です。
- 中国語用リソースは日本語より少なく、英語用ディレクトリには実質的な辞書がありません。未対応辞書を日本語へフォールバックする実装がありますが、対応言語の正式な保証範囲は未確認です。
- HTTP API、GUI、永続DB、認証・権限、外部API連携は実装されていません。

## 文書と実装の差異

- `detail.md` は辞書を `src/dic` と説明していますが、現在の Maven 設定と実装では `resources/dic/` をclasspathの `/dic/` として読み込みます。変更時は現行実装を基準にしてください。
- README はJVMのみを必要条件としていましたが、ソースビルドには POM のコンパイラ設定に対応する Java 17 と Maven が必要です。
