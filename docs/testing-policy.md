# テスト方針

## 現在の構成

テストはJUnit 5を使用し、Mavenの独自 `testSourceDirectory` である `test/jp/livlog/numexp/` に本体と対応するパッケージで配置されています。10クラス、172個の有効な `@Test` があります。Mockito、fixture専用ディレクトリ、外部サービスmock、DBテストはありません。JUnit 4形式の `org.junit.Assert` assertionをJUnit 5テスト内で利用しています。

| 対象 | テストクラス | 有効なテスト数 | 主な観点 |
|---|---|---:|---|
| 統合ファサード | `NormalizeNumexpTest` | 29 | 4種の出力、順序、位置、範囲、除外、入力検証、数値整形 |
| 数値処理 | `NumberNormalizerTest` | 39 | 半角/全角/漢数字、符号、小数、範囲、曖昧数 |
| 数量表現 | `NumericalExpressionNormalizerTest` | 26 | 助数詞、単位、修飾、上下限 |
| 絶対時間 | `AbstimeExpressionNormalizerTest` | 22 | 年月日、時刻、範囲、曖昧値 |
| 相対時間 | `ReltimeExpressionNormalizerTest` | 14 | 前後、絶対・相対部分、上下限 |
| 持続時間 | `DurationExpressionNormalizerTest` | 11 | 単位変換、期間、上下限 |
| 共通処理 | `NormalizerUtilityTest` | 13 | パターン探索と共通変換 |
| 文字判定 | `DigitUtilityTest` | 14 | 数字種別、漢数字、記号、変換例外 |
| 辞書ロード | `DictionaryResourceLoaderTest` | 2 | 日本語フォールバック、欠落エラー |
| CLI | `MainTest` | 2 | 正常出力、引数不足と終了コード |

以前コメントアウトされていたテストは整理済みです。現存APIを対象とする4件は有効化し、削除済みAPIを対象とする2件と重複セットアップ1件は削除しました。

## 実行コマンド

- コンパイル: `mvn compile`
- パッケージ作成: `mvn package`
- テスト: `mvn test`

`mvn package` とリリースプラグインの `clean verify` でもテストが実行されます。テストを意図的にスキップした場合は、ビルド成功を「テスト成功」と報告してはいけません。

## 変更種別ごとの確認

- 数値処理: 半角/全角/漢数字、正負、桁区切り、小数、範囲、無限大、開始・終了位置。
- 数量: 助数詞、SI単位と換算、接頭辞・接尾辞、概数、序数、除外語。
- 絶対時間: 年号、2桁年、日付/時刻、曜日、範囲、未知部分 `X`、上限・下限。
- 相対時間: 前後方向、基準となる絶対部分、期間単位、複合表現。
- 持続時間: 年/月/日/時/分/秒、単位換算、以上・以下・範囲。
- 辞書: 追加語の正常認識だけでなく、他の3種への誤分類、固有名詞、URL、不適切表現の回帰。
- 統合出力: `normalize()` の区切り・フィールド順と `normalizeData()` の各フィールド、入力内の出現順。

正常系に加え、空文字、該当なし、不正または未対応の言語、辞書欠落、`null`、極端に長い入力、数値精度限界を異常系・境界値として検討してください。対応言語は `ja` と `zh`、nullと未知言語の例外契約はテスト済みです。入力サイズと性能の期待値は計測前に推測で固定しないでください。

## 対象外と手動確認

DB、外部API、認証、権限、画面は実装がないため、現時点のテスト対象ではありません。CLIを手動確認する場合は `Main` の `<language> <text>`、標準出力、引数不足時の標準エラーを確認します。辞書変更は代表文と誤認識しやすい周辺文を人間が確認してください。

## テスト不足・要確認

- `normalizeData()` の各表現種別、辞書破損、ログの明示的なテスト範囲。
- 中国語の回帰ケース。
- 並行利用、正式な性能ベンチマーク、大入力、`double` の丸めに関する追加テスト。

## 性能の参考計測

Windows 11 / Java 21で、同一インスタンスへ `3人です。` の繰り返しを渡す単発計測を行いました。1,024文字は約0.33秒、10,240文字は約3.16秒、102,400文字は90秒を超えたため打ち切りました。ウォームアップ、複数試行、メモリ測定を備えた正式なベンチマークではないため、保証値や固定上限には使用しません。利用側では要求レイテンシに応じた入力上限とタイムアウトを設定してください。
